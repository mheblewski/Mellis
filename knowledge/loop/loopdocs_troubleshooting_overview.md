# LoopDocs: first steps when Loop behaves unexpectedly

## Loop phone must use automatic time [section "Use Automatic Time on Loop Phone"]

If automatic time on the Loop phone was turned off and the clock set by hand (not a time-zone change), LoopDocs flags this as a problem: the Loop phone must stay on automatic time.

## Gathering information: screenshots, docs and the Loop Issue Report [section "Gather information"]

- Take a screenshot of the Loop main screen (and of screens such as the message shown when tapping a red loop): recent basal changes, the predicted glucose curve and carb entries tell much of the story. If you missed the moment, Nightscout keeps about the last 48 hours to scroll back through.
- Search LoopDocs for any error message text; the Troubleshoot section and FAQs are updated regularly.
- `Issue Report` in Loop Settings creates a Loop Report, a text file with detailed actions and status; a button at its upper right lets you email it.

## Checking known issues and community groups [section "Check Resources"]

Known problems are listed in GitHub Loop Issues (add to an existing issue rather than opening a duplicate). Zulipchat, the Looped Facebook group and the LoopandLearn Facebook group may already have the answer.

## Asking for help with Loop [section "Ask for Help"]

GitHub Issues suits suspected errors in Loop's behaviour; Facebook and Zulipchat suit questions about use, such as bolus strategies or exercise targets. Include a description, screenshots, the Loop version (top of Loop Settings) and the iOS version. Post in one place only, because the same volunteers read all of them.
